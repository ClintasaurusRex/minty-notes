# Start here

This is the planning pack for Minty Notes, a personal notebook and project workspace. No application code is included.

1. Read MINTY_NOTES_PLAN.md for the product, screen, storage, and build-stage specification.
2. Put these documents in a new Minty Notes repository or otherwise make them readable to Claude Code.
3. Copy the first build instruction from CLAUDE_CODE_HANDOFF.md to begin Stage 0 and Stage 1.
4. Review that working milestone, then use the continuation instructions for later stages.

Recommended delivery: an installable Chrome web app with local data, offline support after setup, and folder backups. The host serves app files only. Actual deployment and optional native desktop packaging come later.

Each build prompt now includes an effort recommendation and guidance on starting a fresh Claude Code conversation versus continuing the current one. Select the branch containing the latest work when starting fresh.
